# Card Toolbar: Sort and Filter

## What This Covers

This document covers the top-toolbar sort and filter controls in the Card Container.

Included controls:
- Sort dropdown
- Filter dropdown (Category + Tags)

---

## Sort Dropdown

### Purpose
Order cards by time or distance.

### Sort Options
- **Newest First**
- **Oldest First**
- **Closest To Me**
- **Closest To Pin**

### How to Use
1. Click **Sort By**.
2. Select one sort option.
3. Click **Apply**.
4. Use **Clear** to remove sorting.

### Distance Sort Requirements
- **Closest To Me** requires current location to be available.
- **Closest To Pin** requires a searched map location (pin) first.

### Notes
- If required location context is missing, users are prompted to set it first.

---

## Filter Dropdown

### Purpose
Narrow cards by category and/or tags.

### Category Options
- River
- Watershed
- Places
- Other

### Tag Filter Behavior
- Add one or more tags.
- Tags are matched as active filters.
- Remove individual tags or clear all.

### How to Use
1. Click **Filter By**.
2. Choose a category (optional).
3. Add tag(s) (optional).
4. Click **Apply**.
5. Click **Clear** to reset category and tags.

### Notes
- Filter badge count reflects active category + tag filter count.
- Category and tags can be used together.

---

## Common Questions

**Q: Can I filter by tags only?**
A: Yes. Category is optional.

**Q: Can I filter by category only?**
A: Yes. Tags are optional.

**Q: Do sort and filter work together?**
A: Yes. Sorting applies to the current filtered result set.
