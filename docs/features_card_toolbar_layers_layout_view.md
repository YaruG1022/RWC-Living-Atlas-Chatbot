# Card Toolbar: Markers, View Mode, and Panel Layout

## What This Covers

This document covers top-toolbar controls related to map marker visibility and Card Container layout.

Included controls:
- Show/Hide Markers
- List/Grid view toggle
- Move panel left/right

---

## Show / Hide Markers

### Purpose
Temporarily hide or show map markers for cards.

### How to Use
1. Click the **Marker** icon button in the toolbar.
2. If markers are visible, they become hidden.
3. Click again to show them.

### Notes
- This changes marker visibility only (display on/off).
- Card data is unchanged.
- Hidden markers can be restored immediately with one click.

---

## List / Grid View Toggle

### Purpose
Switch card presentation style inside the Card Container.

### Modes
- **Grid View**: card tiles
- **List View**: compact row-style list

### How to Use
1. Click the **List/Grid** icon in the toolbar.
2. The panel switches between list and grid mode.

### Notes
- When switching to list mode, panel width may auto-adjust.
- In split-left layout conditions, this toggle can be disabled.
- View choice is remembered in panel state.

---

## Move Panel Left / Right

### Purpose
Move the Card Container to the opposite side of the map.

### How to Use
1. Click the **Left-Right arrows** button.
2. The card panel moves from left to right or right to left.

### Notes
- This is a layout action only.
- Cards, filters, and search state remain intact.

---

## Common Questions

**Q: I switched to list view and panel width changed. Is that expected?**
A: Yes. The panel may resize to keep list content readable.

**Q: Why is list/grid toggle disabled sometimes?**
A: It can be disabled in specific split-left layout constraints.
