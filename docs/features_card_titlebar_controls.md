# Card Container Titlebar Controls

## What This Covers

This document covers the top titlebar controls in the Card Container, excluding card creation.

The titlebar includes:
- Help button
- Tutorial/Onboarding button
- Close panel button
- Card count subtitle ("all cards" or "in view")

---

## Help Button

### Purpose
Open the user manual directly to the Card Container section.

### How to Use
1. Open the Card Container panel.
2. Click the **Help** icon in the titlebar.
3. A new tab opens at the card-container help section.

### Notes
- This does not change card data.
- This is safe to use at any time.

---

## Tutorial / Onboarding Button

### Purpose
Launch the interactive onboarding walkthrough for the Card Container.

### How to Use
1. Click the **Tutorial/Play** icon in the titlebar.
2. Follow the guided steps highlighting toolbar and list actions.

### Notes
- The walkthrough explains panel actions and card interactions.
- It can be opened repeatedly.

---

## Close Panel Button

### Purpose
Collapse the Card Container panel without losing current state.

### How to Use
1. Click the **Close (X)** icon in the titlebar.
2. The panel collapses.
3. Re-open using the panel toggle control.

### Notes
- Current filters/search/view mode are preserved in state.
- Closing the panel does not delete any cards.

---

## Card Count Subtitle

### Purpose
Show quick context for what list is currently displayed.

### Display Format
- `N all cards` when the scope is set to all cards.
- `N in view` when viewport scope is enabled.

### Notes
- Count reflects current category/tag/sort/search/scope results.
- Count updates dynamically as filters change.
