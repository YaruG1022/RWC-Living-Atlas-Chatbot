# Drawing Polygons and Adding Images on the Map

## How to Draw a Polygon on the Map

Use the polygon tool to draw a custom area (e.g., for a watershed boundary card).

### Steps:
1. Click the **Add Tools** button (+ icon) on the map toolbar.
2. Select **Polygon Tools** from the dropdown.
3. The Polygon Drawing modal opens.
4. Click on the map to place polygon vertices (corners). You need at least 3 points.
5. Optionally set the fill color and line style (solid, dashed, etc.).
6. Click **Save** to confirm the polygon.
7. Click **Cancel** to discard and close the tool.

---

## How to Add a PNG Image Overlay on the Map

Use this to pin an image (like a heatmap, map screenshot, or custom graphic) over a specific area on the map.

### Steps:
1. Click the **Add Tools** button (+ icon) on the map toolbar.
2. Select **Add PNG** from the dropdown.
3. A file picker opens — select your PNG image file.
4. The image placement modal opens, showing the image.
5. Place the 4 corner points of the image on the map to define where it should be positioned.
6. Click **Save** to confirm the placement.
7. Click **Cancel** to discard.

**Note:** Only PNG files are accepted for image overlays. The image maximum size per file is 5 MB.

## Common Questions

**Q: How do I draw a polygon area on the map?**
A: Click the Add Tools (+) button on the map toolbar, select "Polygon Tools", then click on the map to draw polygon vertices and save.

**Q: How do I add an image to the map?**
A: Click the Add Tools (+) button, select "Add PNG", choose your PNG file, place the 4 corners on the map, and save.

**Q: How many points do I need for a polygon?**
A: At least 3 points (vertices) are required to form a valid polygon.

**Q: What file types can I use for image overlays?**
A: Only PNG files are supported for map image overlays.
